⌘ OOP LEARNING MODE

Tap a title to open its definition.

1. Class & Object

A Time or Distance class is a blueprint. Variables such as t1 and d1 are objects created from that blueprint.

2. Constructors

A constructor is a special class function called when an object is created. A default constructor uses starting values; a parameterized constructor initializes an object with values, e.g. Time(1, 45, 50).

3. Operator Overloading (+)

Operator overloading lets an operator such as + work with class objects. For example, t1 + t2 can add two time objects using a class-defined operator+ function.

4. Normalization

Normalization converts excess smaller units into larger units. For time, 60 seconds become 1 minute and 60 minutes become 1 hour. For distance, 1,000 metres become 1 kilometre.

5. Encapsulation

Encapsulation means keeping data and the functions that operate on it together inside a class. Access to the data can be controlled using private and public.

6. Examples

Time: 01:45:50 + 00:20:30 = 02:06:20
Distance: 5 km 750 m + 3 km 600 m = 9 km 350 m
